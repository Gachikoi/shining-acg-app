## 功能点 1 · App 壳内满高主内容区

### 1. 功能点简介

个人资料页复用现有 App Header / 侧栏 / 底栏，主内容区可滚动展示资料头与内容区。

### 2. 如何测试

1. 登录后打开 `/app/profile`（或点底栏/侧栏「我」）。
2. 确认未离开 App 壳（顶栏、桌面侧栏或移动底栏仍在）。
3. 拉长/缩短视口，确认内容可滚动且不被底栏遮挡。

### 3. 怎样算通过

- [ ] 页面在现有 App 壳内打开
- [ ] 主内容区可见资料头 + Tab + 网格槽位
- [ ] 未出现独立全屏页替换 App 壳
