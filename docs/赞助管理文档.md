# 赞助管理方案

1. 用一个文档定期更新收支信息
2. 赞助金分为两类：一类是服务器及对象存储开支，这个和项目的基本使用体验息息相关（先使用小主机作为服务器，暂时不存在一类开支）；另一类是iOS开发者账号开支，属于增加应用的进阶体验，这部分金额巨大并且感知不强，所以单列出来。赞助者可以两类进行分别赞助。
3. 赞助金将会全部用于晒你网站相关开支，不会被挪作他用，未使用资金暂存在开发者用于支付服务器等费用的银行卡中。
4. 每次对服务器费用进行付费时，都会按照每位赞助者赞助金所占总赞助金的比例，和其他赞助者分摊费用。
5. 赞助者将会展示在晒你官网进行鸣谢。
