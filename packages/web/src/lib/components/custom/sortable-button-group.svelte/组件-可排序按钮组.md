## 可排序按钮组组件使用文档（SortableButtonGroup）

### 组件位置

- **组件文件**: `packages/web/src/lib/components/custom/sortable-button-group.svelte`
- **依赖**:
  - `packages/web/src/lib/actions/long-press.ts`
  - `packages/web/src/lib/actions/long-press-sort.ts`
  - `packages/web/src/lib/actions/context-popover.ts`
  - `packages/web/src/lib/actions/draggable-scroll.ts`

组件封装了：

- 横向拖动滚动（鼠标拖动导航条）
- 长按拖拽排序（PC + 手机）
- 右键弹出 Popover（PC）
- 可选的顺序持久化（localStorage）

使用者只需要配置一组按钮文本和路由即可；也可以通过 `item` slot 自定义为图片卡片等复杂结构。

---

### 一、快速上手示例

#### 1. 引入组件

```svelte
<script lang="ts">
	import { page } from '$app/state';
	import SortableButtonGroup from '$lib/components/custom/sortable-button-group.svelte';

	const MENU_ITEMS = [
		{ label: '举报受理', href: '/management/report' },
		{ label: '权限管理', href: '/management/permission' },
		{ label: '身份认证', href: '/management/identity' },
		{ label: '分区编辑', href: '/management/section' },
		{ label: '部门编辑', href: '/management/department' },
		{ label: '官网编辑', href: '/management/website' },
		{ label: '通知管理', href: '/management/notice' }
	] as const;

	const STORAGE_KEY = 'management-menu-order';

	let currentPath = $derived(page.url.pathname);
</script>

<SortableButtonGroup
	items={MENU_ITEMS}
	storageKey={STORAGE_KEY}
	isActive={(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')}
/>
```

#### 2. 效果说明

- **PC / 手机通用**
  - 普通点击：直接跳转到 `href`。
  - 右键按钮（PC）：弹出对应按钮的 Popover。
  - 长按：到达长按时间后，
    - 不拖动松手 → 不会弹出 Popover（保留后续扩展空间）；
    - 左右拖动 → 进入排序模式，根据拖动距离与相邻按钮交换位置（可连跳多格）。
- **顺序记忆**
  - 传入 `storageKey` 时，拖拽后的顺序会写入 `localStorage[storageKey]`，刷新仍保持。
  - 不传 `storageKey` 时，仅当前会话内有效。

### 二、Props 详细说明

组件内部 props 定义：

```ts
type ButtonItem = {
	label: string;
	href: string;
};

let {
	items,
	isActive,
	storageKey,
	longPressDuration = 400,
	moveThreshold = 40,
	navClass = '',
	buttonClass = ''
}: {
	items: ButtonItem[];
	isActive?: (item: ButtonItem) => boolean;
	storageKey?: string;
	longPressDuration?: number;
	moveThreshold?: number;
	navClass?: string;
	buttonClass?: string;
} = $props();
```

- **items（必填）**
  - 类型：`{ label: string; href: string }[]`
  - 用来生成每个按钮的文案和跳转链接。
- **isActive（推荐）**
- 类型：`(item: ButtonItem) => boolean | undefined`
- 用于决定某个按钮是否处于激活态（高亮）。
- 组件本身不依赖 URL 或 `page.url.pathname`，你可以按自己的业务规则编写：
  - 基于路由路径：`(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')`
  - 基于业务状态：`(item) => item.key === activeKey`
- **storageKey（可选）**
  - 类型：`string | undefined`
  - 设置后，会将当前按钮顺序写入 `localStorage[storageKey]`，再次进入页面时按该顺序渲染。
  - 不设置时，不做持久化，只在当前会话内排序。
- **longPressDuration（可选，默认 `400`）**
  - 长按判定时间（毫秒）。
  - 调大（如 `600` / `800`）→ 更难触发长按。
  - 调小（如 `250`）→ 更容易触发长按。
- **moveThreshold（可选，默认 `40`）**
  - 拖拽触发“交换位置”所需的最小水平位移（像素）。
  - 调大 → 需要拖更远才换位置（拖拽“更慢”）。
  - 调小 → 轻微移动就会换位（拖拽“更敏感”）。
- **navClass（可选）**
  - 附加在外层 `<nav>` 上的 class。
  - 可用于调整整体高度、间距、背景等。
- **buttonClass（可选）**
  - 附加在单个 `<a>` 按钮上的 class。
  - 可用于局部定制按钮样式，例如宽度、字体等。

### 三、PC / 手机交互行为细节

- **普通点击**
  - PC / 手机：快速点击按钮 → 直接导航到 `href`，不会弹出 Popover。
- **右键（PC）**
  - 在按钮上右键 → 弹出按钮对应的 Popover。
  - Popover 内容目前是一个简单的标题 + 描述，可后续扩展为操作菜单。
- **长按（PC + 手机）**
  - 到达 `longPressDuration` 后：
    - 未发生明显拖动（小范围抖动）：松手时不会弹出 Popover，仅作为一次“长按点击”结束；
    - 发生明显的左右拖动（超过 `moveThreshold`）：
      - 进入拖拽排序模式；
      - 根据拖动距离可以一次移动多格，直到列表边界为止。
  - 拖拽过程中，会临时禁用 `draggableScroll`，避免和横向拖动滚动冲突。

### 四、在其他页面复用的最佳实践

#### 1. 在新页面添加一个二级菜单（默认按钮样式）

示例：在 `+page.svelte` 中添加一个用于模块内部导航的按钮组。

```svelte
<script lang="ts">
	import { page } from '$app/state';
	import SortableButtonGroup from '$lib/components/custom/sortable-button-group.svelte';

	const SUB_TABS = [
		{ label: '总览', href: '/demo/overview' },
		{ label: '报表', href: '/demo/report' },
		{ label: '设置', href: '/demo/settings' }
	];

	const STORAGE_KEY = 'demo-sub-tabs-order';

	let currentPath = $derived(page.url.pathname);
</script>

<SortableButtonGroup
	items={SUB_TABS}
	storageKey={STORAGE_KEY}
	isActive={(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')}
/>
```

#### 2. 使用图片卡片作为可排序项（通过 `item` slot）

```svelte
<SortableButtonGroup
	items={SUB_TABS}
	storageKey={STORAGE_KEY}
	isActive={(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')}
>
	<svelte:fragment slot="item" let:item let:active>
		<div
			class="flex h-16 w-24 items-center justify-center overflow-hidden rounded-xl border transition-colors"
			class:ring-2={active}
			class:ring-red-500={active}
		>
			<img src={item.imageUrl} alt={item.label} class="h-full w-full object-cover" />
		</div>
	</svelte:fragment>
</SortableButtonGroup>
```

> 注意：上例中 `imageUrl` 字段并未在 `ButtonItem` 类型中强制约束，你可以在自己的业务代码里扩展该类型。

#### 3. 只想要“可排序”，不需要持久化

```svelte
<SortableButtonGroup
  items={SUB_TABS}
  isActive={(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')}
  <!-- 不传 storageKey，就不会写 localStorage -->
/>
```

#### 4. 调整长按时间和拖拽灵敏度

```svelte
<SortableButtonGroup
  items={SUB_TABS}
  storageKey={STORAGE_KEY}
  isActive={(item) => currentPath === item.href || currentPath.startsWith(item.href + '/')}
  longPressDuration={600}   <!-- 0.6s 才判定为长按 -->
  moveThreshold={150}       <!-- 需要拖 150px 才会触发换位 -->
/>
```

### 五、内部实现（简要说明，方便以后维护）

- 外层 `<nav>` 使用 `use:draggableScroll`：
  - `direction: 'horizontal'`
  - 根据内部的 `isSorting` 自动启用/禁用拖动滚动。
- 每个按钮 `<a>` 同时挂三个 action：
  - `use:longPressSort`：
    - 统一处理长按 + 拖拽逻辑；
    - 根据移动方向（水平）与相邻元素交换顺序；
    - 通过 `getItems / setItems / onOrderChange` 通知外部更新和持久化。
  - `use:contextPopover`：
    - 拦截 `contextmenu` 事件，触发 `onTrigger` 回调；
    - 默认阻止浏览器右键菜单。
  - 内部再配合 `Popover.Root` / `PopoverTrigger` / `Popover.Content` 实现视觉上的弹出层。

如需对 Popover 内容或按钮结构做高级自定义，可以后续在该组件上增加 slot（例如 `#item`、`#popover`），当前版本主要满足“快速落地可排序按钮组”的需求。
