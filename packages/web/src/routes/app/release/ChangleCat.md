## 六、小结

- **已完成**：发布页主流程（表单、分区、保存/自动保存、上传、CreatePost）、富文本 @ 用户（关注列表 + 过滤）、草稿持久化、意外兜底、媒体选择与 Live Photo。**部分完成**：缩略图长按/右键、@ 点击个人资料（路由未就绪）、重置编辑场景、发布成功跳转。

- **排期**：P1 任务可优先推进（无依赖或依赖就绪）；P2 等图片视频编辑器、横幅组件、帖子详情路由就绪；P3 等后端 API、原生桥接就绪。
